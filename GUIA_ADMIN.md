## 🖼️ Gerenciar Banners

### Como adicionar um banner:
1. Clique em **"Gerenciar Banners"**
2. Clique em **"Adicionar Novo Banner"**
3. **Preencha**:
   - **Título**: Nome do banner
   - **Descrição**: Texto explicativo
   - **Imagem**: Upload da imagem (recomendado: 1200x400px)
   - **Link**: URL para onde o banner leva (opcional)
   - **Ordem**: Posição de exibição
4. Clique em **"Salvar"**

### Dicas:
- Use imagens em **JPG ou PNG**
- Tamanho recomendado: **1200x400 pixels**
- Mantenha arquivos **menores que 2MB**

---

## 👥 Gerenciar Equipe

### Como adicionar um membro:
1. Clique em **"Gerenciar Equipe"**
2. Clique em **"Adicionar Novo Membro"**
3. **Preencha**:
   - **Nome**: Nome completo
   - **Cargo**: Função na rádio
   - **Descrição**: Biografia ou informações
   - **Foto**: Upload da foto (recomendado: 300x300px)
   - **Redes sociais**: Facebook, Instagram, Twitter (opcional)
4. Clique em **"Salvar"**

### Dicas:
- Fotos em formato **quadrado** ficam melhores
- Tamanho recomendado: **300x300 pixels**
- Mantenha descrições **curtas e objetivas**

---

## 📅 Gerenciar Programação

### Como adicionar um programa:
1. Clique em **"Gerenciar Programação"**
2. Clique em **"Adicionar Novo Programa"**
3. **Preencha**:
   - **Dia da semana**: Segunda, Terça, etc.
   - **Horário de início**: Ex: 08:00
   - **Horário de fim**: Ex: 10:00
   - **Título**: Nome do programa
   - **Descrição**: O que acontece no programa
4. Clique em **"Salvar"**

### Dicas:
- Use formato **24h** para horários
- Organize por **ordem cronológica**
- Mantenha descrições **claras e atrativas**

---

## ⚙️ Configurações do Site

### Configurações Básicas:
1. Clique em **"Configurações"**
2. **Preencha**:
   - **Nome do site**: Nome da sua rádio
   - **Logo**: Upload do logo (recomendado: 200x80px)
   - **Favicon**: Ícone do site (16x16px)
   - **E-mail de contato**: Para receber mensagens

### Cores e Visual:
- **Cor principal**: Cor dominante do site
- **Cor de fundo**: Cor de fundo das páginas
- **Cor do texto**: Cor dos textos
- **Cor dos botões**: Cor dos botões
- **Cor dos links**: Cor dos links

### Streaming:
- **URL do streaming**: Link do seu streaming ao vivo
- Exemplo: `https://streaming.example.com/live`

### Redes Sociais:
- **Facebook**: Link do Facebook
- **Instagram**: Link do Instagram
- **YouTube**: Link do YouTube
- **WhatsApp**: Número do WhatsApp (apenas números)

### CSS Customizado:
- Adicione **código CSS** para personalizações avançadas
- Exemplo:
```css
.player-bar {
    background: linear-gradient(45deg, #ff6b6b, #4ecdc4);
}
```

## 🔧 Dicas Importantes

### Upload de Imagens:
- **Formatos aceitos**: JPG, PNG, GIF
- **Tamanho máximo**: 2MB por arquivo
- **Resolução recomendada**: 1200px de largura para banners

### Segurança:
- **Altere a senha** do admin regularmente
- **Faça backup** do banco de dados
- **Mantenha o sistema** atualizado

### Performance:
- **Otimize imagens** antes do upload
- **Use nomes descritivos** para arquivos
- **Mantenha o conteúdo** organizado

## 🆘 Solução de Problemas

### Erro de login:
- Verifique se o e-mail está correto
- Confirme se a senha está certa
- Tente resetar a senha

### Imagens não aparecem:
- Verifique se o arquivo foi uploadado
- Confirme se o formato é aceito
- Verifique o tamanho do arquivo

### Site não carrega:
- Verifique se o XAMPP está rodando
- Confirme se Apache e MySQL estão ativos
- Verifique os logs de erro
