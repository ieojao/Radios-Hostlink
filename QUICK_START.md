# 🚀 Início Rápido - Nova Atalaia Python

## ⚡ Execução Rápida

### 1. Instalar Python
Certifique-se de ter Python 3.8+ instalado:
```bash
python --version
```

### 2. Instalar Dependências
```bash
pip install -r requirements.txt
```

### 3. Executar
```bash
python run.py
```

### 4. Acessar
- **Site**: http://localhost:5000
- **Admin**: http://localhost:5000/admin
- **Login**: admin@novaatalaia.com.br / admin123

## 🐳 Com Docker

### Execução com Docker
```bash
# Construir e executar
docker-compose up --build

# Ou apenas executar
docker-compose up
```

## 🔄 Migração do PHP

Se você tem dados do PHP, migre-os:
```bash
python migrate_php_to_python.py
```

## 📋 Comandos Úteis

```bash
# Verificar configuração
python run.py --check

# Executar em porta diferente
python run.py --port 8080

# Modo debug
python run.py --debug

# Inicializar banco
python run.py --init-db
```
